### What changed in rc.15

**Website: Arabic videos page intro**

rc.14 shortened the videos page intro in every language, but the Arabic page kept the old,
repetitive line (lost while merging the Mac installer work). It now reads
"اختار الصفحة اللي عايز تفهمها ودوس تشغيل." like the other languages.

**Build: steadier Mac installers**

The Mac `.dmg` build retries `hdiutil` when macOS hasn't let go of the new disk image yet,
which made one CI run fail with "Resource temporarily unavailable".

The app is unchanged from rc.14.
