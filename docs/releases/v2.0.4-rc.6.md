### What changed in rc.6

**A public privacy policy**

- New `PRIVACY.md` at the root of the repository, in English and Arabic. It's the
  public copy of the app's Privacy page, so it can be linked from the Microsoft Store
  listing: `https://github.com/Khaymah/internet-monitor/blob/master/PRIVACY.md`.
  The in-app page can't be linked, since it's only served on 127.0.0.1.
- The in-app Privacy page (footer → Privacy) is up to date with everything added since
  2.0.3:
  - `case.json`, which holds the line and account numbers you enter on the Complaints page.
  - ntfy, generic webhooks and the weekly summary as alert destinations.
  - Optional log timestamps, which send a 32-byte hash to freetsa.org.
  - The traceroute that runs when an outage starts.
  - The headless version's network option and the Store version's data folder.
- The README links to the policy, and `docs/microsoft-store.md` gives the exact URL for
  Partner Center.

**Store package name**

- The package's display name now comes from `packaging/msix/identity.json`
  (`display_name`, set to the reserved name "Internet-Monitor"). Partner Center rejected
  the rc.5 package because its name, "Internet Monitor", didn't match the reservation.

### How to test

- [ ] Open `PRIVACY.md` on GitHub: the English and Arabic parts render, and the Arabic part
      reads right to left.
- [ ] In the app, footer → Privacy, in English and in Arabic: the page is dated 5 November
      2026 and lists case.json, ntfy, freetsa.org and the traceroute.
- [ ] The two texts match.
- [ ] Upload the rc.6 `internet-monitor-store.msix` to Partner Center: the display name
      error is gone.

### Known limits

- The app itself works exactly as in rc.5. In the Store version, the Start menu shows
  "Internet-Monitor" (the reserved name); the window and tray still say "Internet Monitor".
- When a future version changes what the app stores or where it connects, `PRIVACY.md`
  and `web/locales/*/legal.json` both need updating, with the new date in
  `web/src/content/legal.ts` and `PRIVACY.md`.
