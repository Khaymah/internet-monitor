### What changed in rc.10

**Router password: reading the router's page over HTTPS**

On a real WE Huawei HG630 V2 the router-password test said "the router's page didn't
answer" even with the right password. That router serves its page over HTTPS with an old,
self-signed certificate, which browsers show as "Not secure".

- The app now tries `https://` first and falls back to `http://`.
- For the router on your home network only, it accepts the older TLS versions and ciphers
  those routers use. The certificate is still not checked (it can't be: it's self-signed),
  and the password is still only ever sent to an address on your home network.
- When the test fails, the message now says why (for example a refused connection or a TLS
  error), and `app.log` records it as `ROUTER page test failed`.

### How to test

- [ ] Settings → App → "Test the router password" with the right password: a message with
      the line speed and noise margin.
- [ ] With a wrong address (for example 192.168.1.250): the error says why it failed.

### Known limits

- Only the Huawei page layout (HG630 V2 and siblings) is read. Other routers still show the
  UPnP details only.
