### What changed in rc.1

**More routers**

Reading the router's own page used to work on the Huawei HG630 V2 only. It is now a set of
drivers; the app finds which one fits your router by itself and the router card says which
one is in use:

- **Huawei** (`huawei-hg`): HG630 V2 as before, and the same family: HG633, HG659, HG658,
  DG8045. Gateways without a DSL page still give the model, connection and data counters.
- **TR-064** (`tr064`): the standard many routers speak (FRITZ!Box, Zyxel and others): data
  counters (64-bit where offered), DSL speed, noise margin and attenuation, connection
  status and uptime. Tried without a password first; the saved password is used only if the
  router asks for one.
- **ZTE, trial** (`zte-new`): newer ZXHN / F6xx firmware: DSL speed, noise margin,
  attenuation, internet connection status and model. No data counters on this generation
  yet. Marked "trial" until someone confirms it on a real router.

The same safety rules apply to every driver: only addresses on your home network, a rejected
password is never retried (ZTE routers lock you out after a few wrong tries), and the app
signs out after each read. If no driver fits, the card says the router isn't supported yet.
How drivers work and how to add one: `docs/routers.md`.

**Help us support your router**

Settings → App → "Help us support your router" builds a report of what your router offers:
its make, model and software version, the features it answers, and the names of the pages
and fields its login page uses. Serial numbers, MAC addresses, Wi-Fi names and keys, your
public IP, user names, passwords, cookies, phone numbers, emails and device names are
removed before you see it. You read it in full, then download it or open a prefilled GitHub
issue and attach it; the app never uploads it. An optional box lets it sign in once with
your saved password, for routers it already knows, and note the names and kinds of the
details returned, never their values.

**Privacy**

The privacy policy now says the app checks whether your router speaks TR-064 (on your home
network only), and how the router report works.

### How to test

- [ ] Huawei HG630 V2 with the password saved: the router card says it reads the router's own
      page (Huawei) and shows the same figures as in 2.0.4.
- [ ] Any other router with UPnP on: the card shows the UPnP figures, and either names a
      driver or says the router isn't supported yet with a link to the report.
- [ ] Settings → App → "Help us support your router" → Create report: read it and check there's
      no serial number, MAC address, Wi-Fi name, public IP or password in it. "Open a GitHub
      issue" opens a prefilled issue with the router's model.
- [ ] A ZTE ZXHN router (WE, Vodafone, Etisalat…) with its password: the card says
      "ZTE, trial" and shows the line speed and noise margin. Please also attach a report.
- [ ] A FRITZ!Box or another TR-064 router: the card says TR-064 and shows data usage.

### Known limits

- Huawei HG633/HG659/HG658/DG8045, TR-064 and ZTE were built from public documentation and
  tested against simulated routers only; each needs a real router to confirm.
- Not supported yet, and why, in `docs/routers.md`: Huawei EchoLife fiber ONTs, older ZTE
  firmware (`Frm_Logintoken` / `getpage.gch`) and TP-Link. Their sign-in or status pages
  aren't documented well enough to build safely, and a wrong guess can lock you out of
  the router. The router report is how we'll add them.
