### What changed in rc.12

**Website: search engine verification, for real this time**

rc.11 read the verification codes from repository variables, but the published site came
out without them. The Google and Bing codes are public by design (they're in every page's
source), so they now live in the site's code as defaults; repository variables or secrets
of the same names still override them.

The app itself is unchanged from rc.10.

### How to test

- [ ] View the source of https://khaymah.github.io/internet-monitor/ after it redeploys:
      it has `google-site-verification` and `msvalidate.01`.
- [ ] Google Search Console and Bing Webmaster Tools verify the site.
