### What changed in rc.11

**Website: search engine verification**

- The website reads the repository variables `GOOGLE_SITE_VERIFICATION`,
  `BING_SITE_VERIFICATION` and `YANDEX_VERIFICATION` when it's built and puts the matching
  `<meta>` tags on every page, including the root address used for Google Search Console.
  Empty variables add nothing.
- The app itself is unchanged from rc.10.

**Website: the app's own pages, and search engines**

- FAQ, What's new and Privacy now use the same design as those pages inside the app (the
  site reads the app's own styles, icons and texts when it's built). New pages: About,
  Contact, Support us and Terms of use, in all five languages.
- Changing the theme plays the same circular reveal as the app (skipped when the system
  asks for reduced motion).
- Every page is reachable from the header ("More pages"), the phone menu and the footer.
- Search engines and AI assistants: a title, description and keywords per page and
  language, social-sharing images per language, structured data (the app, FAQ, how-to
  steps, the video, breadcrumbs), `llms.txt`, and a robots.txt that welcomes search and AI
  crawlers. Each page opens with a one-paragraph answer and a "last updated" date.

### How to test

- [ ] After the website redeploys, view the source of https://khaymah.github.io/internet-monitor/:
      it has the google-site-verification and msvalidate.01 tags.
- [ ] Google Search Console and Bing Webmaster Tools verify the site.
- [ ] The website's FAQ, About, Contact, Support, Privacy and Terms pages look like the app's,
      in Arabic and English, light and dark; the theme button animates.
- [ ] Share a page link on WhatsApp or Facebook: a preview image appears.

### Known limits

- Search engines take days to weeks to index a new site after the sitemap is submitted.
